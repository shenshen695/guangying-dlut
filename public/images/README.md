# 校园影像素材说明

- `map/campus-q-map.jpg`：由原始校园示意图整理出的 Q 版底图。地图上的文字、路线与点位均由网页绘制，方便后续调整。
- `spots/`：已经接入点位卡片和详情页的样片，使用稳定的英文文件名。
- `spot-library/`：原始“机位照片”完整备份，保留中文文件名，供后续筛选和补充点位。

上线前请确认摄影作品版权、出镜人肖像授权以及学校标识的使用范围。

## Q 版底图生成记录

使用内置图像生成工具，以原始 `地图.jpg` 作为空间布局参考。最终提示词要求：保持南北向校园结构与南门、体育场、伯川、主楼、一馆、凌水湖、花墙的相对位置；生成暖色、手绘 3D 等距视角的 Q 版校园插画；适配网页纵向底图；不生成人物、文字、路线、点位、按钮、导航控件、水印或地图服务样式。
