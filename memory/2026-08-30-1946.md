**关于要不要接真 LLM**：如果你想让它更「智能」（比如用户自由输入"想拍点有故事感的黑白照"这种），可以在 `.env` 里配个 API key，把 StyleAdvisor 的决策表换成一次 LLM 调用。但对毕业照这种选项有限的场景，我觉得当前的引导式问答体验更好——用户不用想措辞，点两下就出结果，也不会有 AI 幻觉推荐出不存在的点位。建议先用问答版，真要自由输入再加 LLM。
